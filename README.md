A single line of horror, under 200 characters: a voicemail from the narrator's own number, in their own voice, warning them not to pick up — and then the phone rings again from the kitchen. Written by a deterministic Python program (stdlib only, no network, no randomness) for make.fun's "One Line, One Chill" bounty.

## Run it

```sh
python3 main.py
```
